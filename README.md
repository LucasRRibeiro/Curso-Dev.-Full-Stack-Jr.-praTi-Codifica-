## 🎯 Projeto Final

Desenvolvimento de uma aplicação web completa com:

- Frontend em **ReactJS**
- Backend com **Spring Boot** (API RESTful)
- Banco de dados **MySQL** ou **PostgreSQL**
- Autenticação com **JWT**
- Testes unitários com **JUnit** e **Jest**
- Deploy e controle de versão com **Git/GitHub**
